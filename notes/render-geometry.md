# Геометрия рендера Пятницкой

Актуальный источник — предоставленный пользователем `Vector 32.svg`, сохранённый без изменений в `src/data/pyatnitskaya-regions-source.svg`. Он полностью заменил прежнюю ручную трассировку 1 ноября 2026. Геометрию отдельных вершин не корректировать по старым заметкам.

Исходный SVG содержит один path с сетью границ. Скрипт `python3 scripts/geometry/import-render-regions.py` выделяет шесть замкнутых граней и присваивает им gain/value/profit/revenue/traffic/flow. Скрипт проверяет, что все рёбра происходят из оригинала и ни одного нового ребра не добавлено.

Выходы:
- `public/assets/buildings/pyatnitskaya-lots.svg`: исходная система 2054×1570, шесть именованных групп, геометрия оригинала сохранена.
- `src/data/render-regions.json`: те же шесть областей в координатах фото 5079×3677 для существующего BuildingSelect (подсветка, hover, тултипы, переходы).

Совмещение всей исходной разметки с фото: единый равномерный масштаб 1.24 и сдвиг (1675,1102). Это преобразование применяется ко всему чертежу целиком, без изменения пропорций или индивидуальной подгонки вершин. При необходимости регистрации менять только единое преобразование в скрипте и проверять всё наложение.

Фото `public/assets/buildings/pyatnitskaya-day.png` и SVG используют одну систему масштабирования: object-fit cover/center и xMidYMid slice соответственно. Временный редактор удалён; localStorage не влияет на контуры.
