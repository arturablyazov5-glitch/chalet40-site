# TASK-013: инвентаризация прототипа

Статус относится к обеим языковым версиям общего шаблона всех десяти лотов. Там, где у лота нет исходной схемы этажа или корпуса, она не подменяется другой.

| Функция и файлы прототипа | До переноса | После переноса / отличие |
| --- | --- | --- |
| index.html, main.js, boot.js, dom.js, shell.generated.js: оболочка, shadow DOM и встраивание | Нет | Не переносится: отдельные серверные страницы Astro и общий layout заменяют embed. |
| app.js, property-controller.js: выбор, маршрутизация, ожидание и обработка ошибок загрузки | Аналог | Статические URL и сборка вместо hash/сетевой загрузки; выбор корпуса использует History API. |
| data/records.js, data/property-repository.js, domain/property.js: записи, источник и проверка | Аналог | lots.json, типизированный lib/lots.ts и Zod при сборке; runtime fetch и отмена запросов не нужны. |
| components/property-view.js: метрики, цены, картинки, ссылки и атомарная смена | Есть | Astro рендерит каждый лот на сервере; ссылки и данные доступны без JS. |
| i18n.js, locales/ru.js, locales/en.js, locales/properties.en.js, components/language-switch.js, styles/language.css: язык | Частично | Добавлены RU/EN ссылки на странице лота; URL определяет язык. Память в localStorage, query-параметр и анимация замены текста не перенесены: язык закреплён URL и каждая версия имеет отдельный HTML. |
| components/zoom-cursor.js, styles/cursor.css: стеклянная лупа | Нет | Добавлена для кнопок изображений, fine pointer; слой не перехватывает события. |
| components/number-motion.js, styles/motion.css: счёт и буквы | Нет | Добавлены счёт и появление подписей, заголовка, компаса, метрик; исходные тексты остаются в DOM для доступности. |
| styles/motion.css: кнопки, блик, hover, диалог | Нет | Эффекты ограничены страницами лотов, анимации отключаются при reduced motion. |
| components/dialogs.js: увеличение, фото, клик вне, фокус | Частично | Уже были native dialog, режим фото, Escape и закрытие вне; добавлены очистка изображения и возврат фокуса. |
| styles/render-preview.css: фото и компактные окна | Есть | Сохранены превью, hover и скрытие на компактных окнах. |
| styles/tokens.css, base.css, components.css, layout.css, main.css: композиция, типографика и адаптив | Есть | Сохранены принятые токены и геометрия сайта; стили рядом с компонентом. |
| hero.js, styles/hero.css: выбор лота, стоимость, ссылки и фон | Аналог | Есть ссылки, актуальные данные, History API, Back/Forward; добавлено появление нового фона с blur/opacity при переключении. |
| hero.js: переключение корпуса внутри одного hash-экрана; парковка и retail | Аналог | Обычные маршруты корпуса, retail и парковки вместо переноса SPA/hash-архитектуры. |
| hero.css: последовательное появление всех элементов первого экрана | Нет | Не добавлено: меняет уже принятую композицию и вид страниц вне лотов при загрузке. |
| hero.js: preload и задержка 340 мс перед сменой фона | Нет | Не добавлены: текущий выбор обновляет данные и URL сразу; задержка может расходиться с Back/Forward и создавать видимое несоответствие данных и изображения. |

EN-тексты сайта остаются авторским черновиком на вычитку.
