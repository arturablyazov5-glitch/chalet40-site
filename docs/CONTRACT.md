# Контракт консультации — TASK-008

POST `/api/consult`, JSON, Origin того же сайта. Ответы и защитные ограничения TASK-007 сохранены: `{ok:true}` / `{ok:false,error}`, native/Zod/PHP validation, honeypot, лимит 5/60 и Retry-After, safe errors. Реальные отправки — только серверный PHP либо явно включённый dev transport; по умолчанию dev offline.

| Поле | Значение |
|---|---|
| name | Однострочная строка, 2–100 UTF-16 units после обрезки краевых пробелов |
| method | whatsapp / phone / telegram / max |
| contact | Телефон либо Telegram username; прежняя валидация формата сохранена |
| consent | Только true |
| lot | Необязательный id: lowercase office slug / P13 / K10, ≤64 |
| lotTitle | **Новое необязательное поле**, строка ≤80 UTF-16 units, из словаря/данных текущего языка. Пустое/отсутствующее — вывод id. Старые клиенты совместимы. |
| page | Путь, начинающийся с /, ≤500, без управляющих символов |
| lang | ru / en |
| utm | Только utm_source, utm_medium, utm_campaign, utm_term, utm_content; ≤200 на значение |
| company | Honeypot, включая непустую строку "0" |

Клиент не передаёт доверенный HTML, дату, домен или URL контакта. lotTitle считается недоверенным: PHP проверяет длину/однострочность и экранирует, dev/Zod — аналогично. Подмена названия клиентом не меняет цену, лот или бизнес-данные.

## Карточка менеджеру

- Без эмодзи и символов-иконок. Заголовок жирным, пустая строка, затем Имя, Связь, Помещение, Страница, Язык и Время отдельными строками. Неизвестный корпус не добавляется.
- parse_mode=HTML, previews отключены. Только `<b>`, `<a href="…">`, `<code>`; без вложенных link/code-сущностей.
- Имя; способ связи и действие; название помещения и человекочитаемый корпус / паркинг с этажом; ссылка с путём без домена и полным URL в href; RU/EN и серверная дата `dd.MM.yyyy, HH:mm (МСК)` в Europe/Moscow; при наличии — строка UTM в фиксированном порядке.
- Номер — в code, рядом tel-ссылка «Позвонить» или https://wa.me/цифры «Написать». Telegram — кликабельный https://t.me/username с отображением @username. Передавайте международный номер с кодом страны.
- origin берётся из src/data/consult-message.json, экспортируется как siteOrigin; пользователь не задаёт домен. Начальные // не позволяют сменить origin. Адрес страницы кодируется, query/fragment не переносятся (UTM передаётся отдельно).
- PHP: каждое пользовательское текстовое значение и href проходит `htmlspecialchars(..., ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8')`; dev использует эквивалентные сущности, включая &#039;. Значения не превращаются в теги.
- API отвергает переводы строк, управляющие и bidi-коды. Formatter дополнительно заменяет их пробелами при прямом вызове.
- Полный HTML ≤4096 UTF-16 units **до** Telegram parsing (консервативнее лимита после parsing). Поля клиппируются по экранированным Unicode code points с …, сущности/теги не разрываются. UTM — до 80 экранированных units на значение. При гипертрофированном URL >1200 units адрес показывается сокращённым code-текстом с отдельной ссылкой «Открыть сайт»; ссылки на несуществующий усечённый путь не создаются. Обычные URL сайта передаются полностью.

## Единообразие и проверка

Канонические строки/лимиты находятся в consult-message.json; build кладёт её в dist/api/message-format.json. PHP helper — api/telegram-message.php, dev — lib/telegram-message.ts. 16 golden-фикстур покрывают методы, экранирование, усечение, UTM, парковку, fallback id и переход московской даты. Независимый JS-файл воспроизводит PHP-функцию на том же наборе; hash исходника PHP требует пересмотра фикстур при изменении. PHP **не исполняется** этим тестом; нативную проверку выполняют на PHP-среде. Реальную отправку тесты не делают, transport подменяется.
